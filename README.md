# مقهى خليل — الخادم الخلفي (Backend)

خادم بسيط يربط بين تطبيق الزبون (الطلب عبر QR) ولوحة تحكم صاحب المقهى بشكل لحظي (Real-time).

## التقنيات المستخدمة
- **Express** — خادم الـ API
- **Socket.io** — لبث الطلبات لحظياً (بدون تحديث الصفحة يدوياً)
- **SQLite المدمجة في Node.js** (`node:sqlite`) — قاعدة بيانات فعلية بدون تثبيت أي برنامج خارجي أو خدمة سحابية منفصلة

## التشغيل محلياً على جهازك

يتطلب Node.js نسخة 22.5 أو أحدث (بسبب `node:sqlite`).

```bash
cd khalil-backend
npm install
npm start
```

الخادم بيشتغل على: `http://localhost:3000`

جرّب: افتح `http://localhost:3000/api/health` في المتصفح — إذا شفت `{"ok":true,...}` فكل شيء تمام.

## نقاط الـ API

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/api/menu` | قائمة المقهى الكاملة |
| GET | `/api/orders` | كل الطلبات (لوحة صاحب المقهى) |
| GET | `/api/orders/:id` | طلب واحد (تتبع الزبون) |
| POST | `/api/orders` | إنشاء طلب جديد |
| PATCH | `/api/orders/:id/status` | تغيير حالة الطلب (`new` → `preparing` → `ready` → `completed`) |

### مثال: إنشاء طلب
```bash
curl -X POST http://localhost:3000/api/orders \
  -H "Content-Type: application/json" \
  -d '{"tableNumber": 7, "items": [{"name":"كابوتشينو","qty":1,"price":14,"size":"كبير","sugar":"نص طوبة"}]}'
```

## أحداث Socket.io اللحظية
- `order:new` — يُبث فور تأكيد الزبون لطلبه (تستمع له لوحة صاحب المقهى)
- `order:updated` — يُبث فور تغيير حالة الطلب (تستمع له لوحة صاحب المقهى وشاشة تتبع الزبون)

## النشر على الإنترنت (باش يصير عندك رابط حقيقي ورمز QR شغّال)

أسهل الخيارات المجانية أو شبه المجانية للبداية:
1. **Railway** (railway.app) — يدعم Node.js وقواعد البيانات مباشرة، الأسهل للمبتدئين
2. **Render** (render.com) — خطة مجانية تكفي للتجربة الأولى
3. **Fly.io** — مناسب لو حبيت تحكم أكتر بالسيرفر

الخطوات العامة تقريباً متشابهة بين الثلاثة:
1. ارفع هذا المجلد لمستودع GitHub
2. اربط حساب GitHub بمنصة النشر
3. حدد أن نقطة التشغيل هي `npm start`
4. بعد النشر بتاخذ رابط حقيقي زي `https://khalil-cafe.up.railway.app`
5. حينها نقدر نولّد رمز QR حقيقي يشير لهذا الرابط، ويشتغل مع أي كاميرا هاتف عادية

## ملاحظة عن قاعدة البيانات
هذا الإعداد يستخدم ملف SQLite محلي (`khalil.db`) — ممتاز للتجربة وحتى للانطلاقة الأولى بمقهى واحد.
لو التطبيق كبر لعدة مقاهي أو حمل زوار عالي، الخطوة الطبيعية بعدها هي الانتقال لقاعدة بيانات سحابية زي PostgreSQL (مثلاً عبر Supabase أو Neon).
